# Registro de Instagram

`history.jsonl` se crea cuando se publica el primer carrusel. Cada línea debe
tener esta forma:

```json
{"slug":"bachue","published_at":"2026-07-25T18:00:00-05:00","template_id":"secuencia_serpentina","motif":"double_curve","palette_id":"laguna","cover_mode":"image","assets":["bachue-horizontal","bachue-vertical","bachue-retorno"]}
```

No registrar borradores: el historial representa uso público real y alimenta la
rotación antirrepetición.

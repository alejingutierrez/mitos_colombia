# Referencias aportadas por el usuario · 2026-09-19

Ocho referencias para mejorar las 25 composiciones existentes. Se conservan
como documentación de dirección de arte; no se incorporan a los PNG publicados.

- 01–03: continuidad entre láminas, recortes, titulares amplios y notas de papel.
- 04: formas orgánicas a gran escala y contraste cromático.
- 05: fotografías que llenan el lienzo con tipografía superpuesta.
- 06: alternancia entre fotografía y carteles tipográficos con símbolos grandes.
- 07: encuadres grandes, notas superpuestas y composición asimétrica.
- 08: texto legible sobre fotografía y llamadas a seguir leyendo.

La adaptación mantiene Asimovian, Noto Sans Display, diez láminas, cinco
versiones por tipo y las imágenes propias del mito. Las fotografías llenan el
fondo; alternamos velos locales de contraste con notas claras sobre la escena.
El PNG abstracto crece en las pausas. Una línea atraviesa las láminas por debajo
del velo para no competir con las palabras.

Se mide el contraste real del fondo renderizado bajo las cajas de los
caracteres: muestreo conservador cada seis píxeles, umbral 4,5:1. Los cruces entre
textos, adornos y bordes siguen bloqueando la exportación. Las superposiciones
sobre fotografías solo pasan cuando además pasa el contraste.

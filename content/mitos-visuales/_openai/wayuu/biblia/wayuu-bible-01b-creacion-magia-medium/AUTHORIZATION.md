# Autorización de referencia local generada

Fecha: 2026-09-03

El propietario editorial aprobó reenviar a OpenAI Images activos generados por
este mismo pipeline únicamente cuando sea realmente necesario para conservar
continuidad. No autoriza por defecto fotos, documentos u otros archivos locales.

Esta tanda cumple la regla de necesidad porque
`creacion-wayuu__magia--regla` depende explícitamente de
`creacion-wayuu__ancla--canon`: debe conservar cámara, geografía, escala y
materialidad y avanzar solamente el estado de agua, semillas y germinación.

- Entrada autorizada:
  `output/imagegen/wayuu/wayuu-bible-01-creacion-medium/creacion-wayuu__ancla--canon.jpeg`
- Destino: OpenAI Images API.
- Uso: referencia/objetivo de continuidad visual para una sola edición.
- Contenido: paisaje generado por el pipeline, sin personas ni datos personales.

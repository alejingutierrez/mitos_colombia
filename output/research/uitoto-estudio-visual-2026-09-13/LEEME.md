# Estudio visual y simbólico uitoto

Abrir `atlas-visual.html` para las imágenes originales enlazadas y filtros. Requiere internet para cargar imágenes. Abrir `dossier.html` o `estudio-visual-uitoto.pdf` para la investigación y sus citas. `dossier.md` es la versión editable.

Hay 38 fuentes y 32 referentes, 15 con imágenes originales enlazadas. Las fichas declaran acceso parcial, autoría, territorio, crédito y límites. Colombia es el foco; Perú es comparación explícita. No se han generado imágenes ni alterado el corpus del proyecto.

`fuentes.csv` y `referentes-visuales.csv` usan UTF-8 con BOM y conservan URLs. `investigacion.json` contiene los datos. `paleta-editorial.svg` es una interpretación editorial, no un estándar cultural.

Reconstrucción: ejecutar `construir.py` con Python y ReportLab disponibles. El script no descarga medios. El PDF contiene análisis, tablas y la paleta; las fotografías se consultan en el atlas desde los servidores originales.
